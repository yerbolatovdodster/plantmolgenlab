# Сайт лаборатории — plantmolgenlab.kz

Статический сайт на [Hugo](https://gohugo.io). Три языка: русский (основной), казахский, английский.

- **Сайт:** https://plantmolgenlab.kz
- **Приложение для расчётов:** https://croppopstructure.plantmolgenlab.kz (работает на сервере лаборатории)

---

## Как редактировать (без программирования)

Сайт редактируется в браузере через **Pages CMS**:

1. Откройте https://app.pagescms.org и войдите через аккаунт GitHub.
2. Выберите репозиторий `plantmolgenlab`.
3. Слева разделы: «Новости», «Команда», «Публикации», «Исследования».
4. Внесите изменения и нажмите **Save**.
5. Через 1–3 минуты изменения появятся на сайте.

Доступ к редактированию есть у тех, кого добавили в организацию на GitHub.

### Добавить новость
«Новости (рус)» → **Add an entry** → заголовок, дата, текст, при желании картинка → **Save**.
Перевод на казахский и английский добавляется так же в разделах «Жаңалықтар (қаз)» и «News (eng)». Если перевода нет, новость просто не появится в этой языковой версии.

### Добавить сотрудника
«Команда» → внизу списка **Add an item** → имя, группа (руководитель / сотрудник / студент / выпускник), должность на трёх языках, фото → **Save**.
Без фото на сайте показываются инициалы. Порядок людей на сайте совпадает с порядком в списке.

### Добавить публикацию
«Публикации» → **Add an item** → год, название, авторы, журнал, DOI → **Save**.
Статьи сами группируются по годам.

### Если что-то сломалось
Вся история изменений хранится в GitHub. Любую правку можно откатить: репозиторий → **Commits** → нужный коммит → **Revert**.

## Структура

```
content/ru|kk|en/     тексты страниц на каждом языке
  _index.md           главная (подзаголовок, цифры-факты, подписи блоков)
  projects/education.md  обучение, конференции и партнёры
  research/           направления исследований
  news/               новости
  tools/_index.md     страница CropPopStructure
  contact.md          контакты
data/team.yaml        сотрудники (все языки в одном файле)
data/publications.yaml публикации (статьи и монографии)
data/projects.yaml    гранты и международные проекты
data/cultivars.yaml   сорта, созданные при участии лаборатории
static/images/        фото и картинки
hugo.toml             название, меню, адрес, телефон, почта, ссылки
static/images/logo.svg логотип (векторный)
i18n/                 подписи интерфейса (кнопки, заголовки) на трёх языках
layouts/, assets/     шаблоны, стили и скрипт графика на главной
.pages.yml            настройки Pages CMS
```

Адрес, почта и ссылка на приложение меняются в `hugo.toml` (раздел `[params]` и `[languages.*.params]`).

## Автоматические публикации (OpenAlex)

Раз в неделю GitHub сам загружает статьи сотрудников из [OpenAlex](https://openalex.org) по их ORCID.

- ORCID вписывается в **Pages CMS → Команда → ORCID**. Чем больше сотрудников с ORCID, тем полнее список.
- Найденные статьи сохраняются в `data/publications_auto.yaml`. Этот файл не редактируйте, он перезаписывается.
- Ручной список **Публикации (вручную)** остаётся: туда добавляются монографии, каталоги и статьи, которых нет в базах.
- Если статья есть в обоих списках (одинаковый DOI), на сайте показывается ручная версия.
- Скрыть ошибочно найденную статью: добавьте её в ручной список с тем же DOI и отметьте **«Скрыть на сайте»**.
- Запустить обновление сразу: **Actions → Update publications → Run workflow**.
- Сотрудники лаборатории в списке авторов выделяются жирным, рядом со статьёй показывается число цитирований.

## Публикация

### Вариант А: хостинг (hoster.kz, ps.kz и т.п.)
При каждом изменении GitHub Actions собирает сайт и загружает его на хостинг по FTP (`.github/workflows/deploy.yml`).

Один раз: репозиторий → **Settings → Secrets and variables → Actions → New repository secret**:

| Секрет | Пример |
|---|---|
| `FTP_SERVER` | `ftp.plantmolgenlab.kz` (из панели хостинга) |
| `FTP_USERNAME` | логин FTP |
| `FTP_PASSWORD` | пароль FTP |
| `FTP_SERVER_DIR` | `public_html/` (со слешем на конце) |

Если хостинг не поддерживает FTPS, в `deploy.yml` замените `protocol: ftps` на `protocol: ftp`.

### Вариант Б: свой сервер
Используйте `scripts/update.sh` (инструкция внутри файла) и nginx, который отдаёт папку `/var/www/plantmolgenlab`. Файл `deploy.yml` в этом случае можно удалить.
